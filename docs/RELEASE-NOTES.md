# 填记 0.1.0

记住网页普通输入框中的常用内容，点击字段旁的按钮即可搜索、选择回填。数据仅保存在本机。

## 功能

- 主动启用站点后，输入完成离开字段时保存历史。
- 点击输入框旁的按钮，搜索、选择历史值回填当前字段。
- 按站点、端口、页面和字段区分记录，避免不同输入框混用历史。
- 每字段保留最近 30 条，支持删除单条、字段或站点记录。
- 历史仅保存在本机，不使用服务器或云同步，不主动提交表单。

## 下载与安装

下载本发布的 `tianji-0.1.0.zip`，解压到一个固定目录。

Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。

打开目标网页后，点击工具栏“填记”，选择“启用本站记录”。首次使用请先在非敏感字段试用。

源码包为 `tianji-source-0.1.0.zip`。普通使用无需安装 Node.js，也无需自行构建。

## 已知范围

支持普通 input 和 textarea，不支持 iframe、复杂自定义下拉和网页封闭 Shadow DOM 内的字段。跳过密码类型和可识别的敏感字段；本机明文历史适用于非敏感参数，不是密码保险库。

已通过 6 项单元测试、10 项真实 Chrome 场景检查。Edge 尚未实测，真实用户网站不在自动化测试范围内。

手动安装不会自动更新，升级时保留原扩展目录并重新加载，勿先卸载。本机历史目前没有导出和备份功能。
